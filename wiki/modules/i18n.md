# i18n

## 目的

说明界面英中切换怎么存、怎么切，以及零件名不翻译。

## 当前判断

src/i18n.js 提供 en / zh。localStorage 键 moonshot.lang。快捷键 L 切换语言。
浏览器里 window.__moonshot.setLang 可直接切。查表函数是 t(key)。
零件显示名保持英文。
截图：logs/shots/i18n-zh-*.png（vab / pad / lko-map / duna-map）。
源文件 src/i18n.js 当时仍未提交；除非后来单独提交，不要假设已经在 git 里。

## 关键入口

src/i18n.js
src/main.js 挂 window.__moonshot.setLang
MCP：ksp_lang
截图目录：logs/shots/

## 边界

只翻译 UI 文案，不翻译 PARTS 的英文 name。
无 DOM 时 setLang 仍改内存语言，localStorage 写失败就忽略。

## 已知问题

中文截图证明 UI 能切；零件面板仍是英文名，这是故意的。
