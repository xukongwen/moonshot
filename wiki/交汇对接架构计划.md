# 交汇对接架构计划

## 目的

北极星：世界里至少两艘船。人（和 agent）能选定目标、交汇、对接。每一刀的人类新操作都要有 MCP。R1–R6 已验收：交汇 2336 m / 8.34 m/s；硬对接可分离；截图 rdv-map / rdv-hud / rdv-close / dock-hard。版本将是 0.1.3。

## 当前判断

R1–R6 已验收：交汇 2336 m / 8.34 m/s；硬对接可分离；截图 rdv-map / rdv-hud / rdv-close / dock-hard。版本将是 0.1.3。

会话已是 `vessels[]` + `activeId`，`this.st` 仍是活动船别名。零件有 `dock-port-s`、`rcs-block`（v1 RCS 不耗燃料，但船上必须有该件）。存档 formatVersion 2（仍读 v1 单船 `flight`）。机动节点不存在；交汇用油门 / `ksp_point` / SAS / 时间加速。

已拍板：

1. 会话从「一艘 st」变成 `vessels[]` + `activeId`。目标船同一套物理（近处逐步积分，远处可 rails）。
2. 先交汇，后对接。交汇不依赖机动节点。
3. 对接端口是新零件。先做 1.25 m 堆叠口 `dock-port-s`。只允许同尺寸对上。
4. 捕获：距离、对准、接近速度过门槛 → 软对接 → 硬对接。硬对接后两船焊住（保持两个 body、锁相对位姿），可分离。第一版不做零件树合并重算。
5. 对接需要最小 RCS（平移）。没有 RCS、用主引擎怼，不可验收。RCS 是对接刀的一部分，不另开史诗。
6. 地图和 HUD 从 R2 起就要能看见目标。图有真相。
7. 存档必须能存多船 + 目标 + 焊接状态，否则交汇飞完无法继续。升级到 formatVersion 2（`vessels[]` + `activeId` + 目标 + 焊接）；仍能读 v1 单船 `flight`。

平移键位写死：I/K 前/后，J/L 左/右，H/N 上/下。现有 WASD 仍是姿态。

版本保持 0.1.N。打板 v0.1.3。不要加 Ike / Jool。

## 边界

第一版不做：

- 机动节点 UI
- 爪子、燃料管、货舱、过桥
- 不同尺寸口转接
- 自动对接电脑（可以后做；第一版人 / agent 手飞）
- Ike / Jool
- 升 1.x

没有 RCS 的主引擎硬怼不可验收。RCS v1 不耗燃料，但必须有 `rcs-block`。
