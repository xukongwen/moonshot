# 卫星计划

## 目的

通信和卫星拍照。服务物流脊梁（以后订单/住客要能看见和说话）。0.1.x 先做基础设施。人能看见的，MCP 也能看见。不要超级零件。不要改火箭物理。不要发明没飞过的遥测。

## 当前判断

目录已有 `sat-bus-s` / `antenna-comm` / `cam-nadir`（S1）。载人仍是 `pod-mk1` / `pod-mk2`。控制力矩来自 `def.pod.torque`。

电力已有：一艘一个 `st.ec`，OX-STAT 共面侧翼，Z-100。`ec=0` 只死 SAS。电力计划写过「先不做无人核心锁死」（现在只有载人舱）——现在要上无人卫星，必须补「脑子」。

扔下的助推已经是船。没有探针的残骸不该还能飞。

太阳/食几何已有（`getInertialState` → Kerbol，圆柱食）。通信遮挡复用这套，不另写轨道积分。

版本 `0.1.1.x`。不改火箭物理、不改星球尺度。S1–S4 已做，打板 0.1.1.2。S5–S6 未做。数字只写飞过的。

已拍板：

1. 第一批零件，不造超级件：
   - `sat-bus-s`：1.25 m 方盒子星体，Pods（优先少改：放 Pods 并标无人；若 VAB 已按 `CATEGORIES` 走、加一类 Probe 也行）。质量约 200–300 kg，自带小 `ecCap`（约 50）和小 `pod.torque`（弱于 mk1）。这是脑子。
   - `antenna-comm`：径向小抛物面，Utility，约 20–40 kg。通信要有它。
   - `cam-nadir`：径向或星体底部朝下的相机，Utility，约 30–50 kg。拍照要有它。
   - 板和电池用现成 OX-STAT + Z-100，不新造板。
2. 无人规则：船上至少一活 `pod` 或 `sat-bus`（probe）才能指挥。没有脑子：不接受油门/SAS/分级（残骸保持现在的漂）。`ec=0` 仍只死轮子，不拆脑子。
3. 通信第一刀：天线 + 到 **科比因** 的几何通视。地面点锁 **科比因地心**（不是 KSC）：被星球挡住即断，和现有食几何同类。当前 SOI 天体挡视线则断；Kerbin SOI 再挡 Mun。通 = 能说话，断 = 静音。不做完整中继网、不做多地面站、不做延迟。
4. 拍照第一刀：有相机、通视地面、花一点 EC，拍 **真画面**（headed / canvas，朝天底）。存进相册（`logs/shots/sat-*.png` 或游戏内列表）。人能看，MCP 能取同一张。不发明「识别出的城市名」。
5. 新人类操作必须有 MCP：拍照键 → `ksp_sat_photo`；通信状态进遥测（`comm` / `commReason`）。没有展开天线键就不新造控制工具。
6. 库存：一艘小卫星（名字以后定，如 Kerbin Eye），`sat-bus-s` + 两翼 OX-STAT + Z-100 + 天线 + 相机。可单独轨道出生，或当 Express 载荷（第一刀单独出生更简单，对接当载荷往后放）。
7. 不改火箭物理、不改星球大小、不作弊灌通视。
8. Agent 检查：夜里/没电/没通视各写一句真字段。不能白拍照。

## 切片

**S1 星体零件** — 已做。bus / 天线 / 相机进目录和 vesselviz。库存 Kerbin Eye。还不会飞无人、不会通信、不会拍。镜头：`logs/shots/sat-s1.png`。

**S2 无人能飞** — 已做。`hasBrain(parts)`：活着的 `def.pod` 或 `def.probe === true`。探针船能 SAS / 指向 / hold。没脑子的残骸不能油门 / SAS / 分级。S2 之后没脑子的助推不能开，回收要另加探针。镜头：`logs/shots/sat-s2-hold.png`。

**S3 通信** — 已做。天线 + 到**科比因地心**的几何通视（不是 KSC）。复用 `vesselInertialPos` + `getInertialState`，和食同一套圆柱/圆盘。Kerbin 自己是目标，不挡链路：**LKO 夜里仍通**（`eclipsed` 为真也不静音）。缪恩背面（Mun 挡地心）才断。载人 `commReason: crew`，不绑天线（Hopper / Express / Hauler 照飞）。探针：没天线 `no-antenna`，挡住 `occulted:<body>`。HUD 通信 通/断。镜头：`logs/shots/sat-s3-comm-on.png`（LKO 白天 通）/ `logs/shots/sat-s3-comm-off.png`（缪恩背面 断）。

**S4 拍照** — 已做。真天底：`Flight.takePhoto()` 把船藏起来，专用相机在原点看向当前 SOI 天体网格（不是追机位）。人键 C / 按钮 拍照 [C]。花 **PHOTO_EC = 5**（Kerbin Eye 80 km 白天飞过：电 150 → 145）。相册 `st.album`：`{ t, body, alt, ecSpent, path? }`。镜头：`logs/shots/sat-s4-nadir.png`（天底地面铺满，蓝绿科比因，不是卫星肖像）+ `logs/shots/sat-s4-context.png`（同一时刻追机位，星在科比因上）。`ksp_sat_photo` 跟 S4 一起落地（wiki lock 5：新人类操作必须有 MCP），无头只记账不造 PNG。遥测 `albumN` / `photoEc`。不发明城市名。

**S5 MCP + 检查** — 未做。检查句（夜里/没电/没通视）。`ksp_sat_photo` 已在 S4 落地，S5 不再重做工具。

**S6 图有真相** — 未做。有头：卫星外形、通信通/断、一张天底照。数字只写那次飞的。

## 关键入口

- `src/parts.js` — `CATEGORIES`；舱 `pod.torque` / `ecCap`；S1 已加 `sat-bus-s` / `antenna-comm` / `cam-nadir`
- `src/vesselviz.js` — 径向件；板=共面静态侧翼
- `src/power.js` — `stepEC` / 通量 / 食；拍照花 EC 走这里
- `src/comms.js` — `commState` / `canCommand` / `hasCrew` / `hasAntenna`；遮挡复用 `vesselInertialPos` + `getInertialState`
- `src/constants.js` — `BODIES` / `getInertialState`（通信遮挡复用，不另写积分）
- `src/photo.js` — `PHOTO_EC` / `canPhoto` / `payPhoto` / 相册
- `src/flight.js` — 指挥、分级、残骸漂；`takePhoto()` 真天底
- `src/hud.js` · `src/save.js` — 人能看见的要能存
- `mcp/session.mjs` `telemetry()` · `mcp/server.mjs` — `comm` / `commReason`；拍照键 `ksp_sat_photo`
- `src/agent-check.js` — 夜里 / 没电 / 没通视各一句真字段
- `src/stock.js` — 库存小卫星（第一刀单独轨道出生）
- `wiki/电力计划.md` — 电已有；「先不做无人核心锁死」在本计划补脑子
- `wiki/总体计划.md`

## 边界

第一版不做：

- 展开天线、跟踪阵、中继网、Duna 深空网
- 合成孔径、自动识别地标、发明城市名
- 多地面站、信号延迟、作弊灌通视
- 改火箭物理、改星球大小、Ike / Jool
- 发明没飞过的遥测
- 升 1.x
