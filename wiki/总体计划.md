# 总体计划

## 目的

把「KSP + 动物之森 + 我的世界」收成一份会改的北极星，避免三款游戏平铺。这是长期方向，不是本周任务单。想法会随时更新，以本页和用户最新口说为准。

## 当前判断

这个 fork 要做成 **agent 和人都能玩的原生 AI 游戏**：人类能做的每一步，AI 都能做（MCP 不欠账）。

玩法脊梁只有一条：**有居民的小世界之间，跑自动化星际物流。**

- **KSP** 是路：火箭、轨道、交汇对接、多船。
- **动物之森** 是为什么跑：每个小星球住着有需求的小动物。大部分是真 agent（对话和行为由 AI 生成），少数手写。部分小动物能开船。
- **我的世界** 是路和家怎么修：星球上用简单方块建造。更远的未来，飞船拼接也改成这种建造，而不是永远停在现在的零件树 VAB。

星球最终要 **小**（现在的 Kerbin 尺度太大）。**现在暂时不改大小。** 先把基础设施做硬，换代再说尺度。

这是 Nonos 的第一个内置游戏。现在只保证世界能被外部 agent 干净地驱动；怎么走进 Nonos（房间 / 窗口 / 走进去）以后再设计，不在 0.1.x 做。

飞之前先过 Δv 预算；失败写成病例再改一刀。

玩法是飞前总图 + 脚本肌肉 + 结点上的 agent，超长脚本不是目标。脚本只做无判断的短动作；agent 起飞前先做整体规划，再在命名结点上读燃料、轨道、剩余级和预算，切下一刀。出错回上一个结点快照，改计划再往下。可恢复的失误是难度，不是必须一次飞完美。见 wiki/modules/play-loop.md。 游戏内要能看见规划：人提粗需求，agent 写出总图、拆刀、一刀一刀飞。切片见 [游戏内Agent计划.md](./游戏内Agent计划.md)。

版本继续 `0.1.N`。升 1.x 必须用户亲口说「出正式版」。换代（改尺度、方块、真村民）只有用户说换代才 `--era`。

## 阶段

### 现在 · 0.1.x 基础设施（不改尺度）

1. **MCP 不欠账。** 每加一个人类操作，就加对应 MCP。已有飞行、VAB、存档、交汇对接。
2. **货物。** 物流的原子。没有货就没有需求，不要先做村民再倒推货物。
3. **第一张订单。** 一个手写小动物 + 一个能飞完的需求（例如某星缺一种货）。图有真相。
4. **着陆。** Mun pad→软着陆→回家已测过（触地 2.87 / 10.74 m/s）。Duna 从低轨软着陆已测过（9.99 m/s）。2026-08-16 agent 路径 pad→Duna 落地→回家已飞通（落地 5849 kg；Kerbin 触地 1.18 m/s / 317 kg），瑕疵照写，见 [2026-08-16-agent-duna-往返.md](./2026-08-16-agent-duna-往返.md)。图：logs/shots/mun-landed.png、agent-fly-land.png、agent-fly-kerbin-land.png。
5. **玩法循环。** 脚本肌肉 + 结点上的 agent；超长脚本不是目标。见 wiki/modules/play-loop.md。游戏内面板与分步执行见 [游戏内Agent计划.md](./游戏内Agent计划.md)（A1–A6 已做）。
6. **不做：** 体素、改星球半径、五十个真 AI 村民、生涯科技树、Ike / Jool。

### 下一档 · 小星球（用户说换代才动）

尺度收到「步行能绕、轨道很短、从天上能看见整个家」。这是动森和方块能成立的物理前提。现有 Kerbol 树可映射，不必先加新星。

### 住客

每星先 4–8 个有名字的，像动森，不要一上来五十个。大部分真 agent，少数手写（商店、教程、稳定合同）。部分会开船，让世界自己动。

### 物流自动化

需求 → 订单 → 航线 → 货船自己跑。玩家/agent 开新线、修节点、去串门。这是主循环，不是装饰。

### 建造

先零件级：发射台、仓库、栖居舱。再星球方块。更后：飞船也用方块拼，替换现在的 VAB。现在的拼接先留着。

### 进入 Nonos

Moonshot 是 Nonos 里的一块地，不是嵌进去的网页。等 MCP 世界干净、货物和第一张订单成立，再单独开刀怎么走进去。
