# 电力计划

## 目的

影子断电、板朝太阳、夜里吃电池、没电丢姿态。先有电这个量，再有太阳和影子，再进目录和库存船。人能看见的，MCP 也能看见。不要超级零件。不要改火箭物理。不要发明没飞过的遥测。

## 当前判断

E1–E6、共面侧翼、LT-2 收起都已做，打板 0.1.1.1。船上有 EC 池（一艘一个 `st.ec`）、舱缓冲、Z-100、OX-STAT 侧翼。SAS 出力才耗电；`ec=0` 轮子死。库存 Express / Reuser / Hauler：指挥舱 host 0 两块板 + 一块电池，助推最后 XL 再一块电池。数字只写探针飞过的，见下面切片。

旧入口仍在：`src/parts.js` `CATEGORIES` 现已含 `panel-oxstat` / `batt-z100`。`pod-mk1` torque 6000 + 50 EC、`pod-mk2` 16000 + 150 EC。`stepAttitude` 只在 `ec>0` 给 `podTorque`。Agent `pointState` / `driveBurn` 按同一 SAS 费率付钱。rails / warp 走 `stepECOnRails`。太阳矢量用 `getInertialState` 指向 Kerbol，不用装饰用的 `SUNDIR`。

用户要先计划。已拍板：

1. 资源名 **EC**（ElectricCharge）。一艘船一个池。
2. EC=0：SAS 和反作用轮死。发动机、分级、伞、腿仍可用。先不做无人核心锁死（现在只有载人舱）。
3. 第一批板是径向静板（一直亮，`max(0, n·sun) * flux`）。没有展开键、没有跟踪、没有 RTG / 燃料电池 / 离子。
4. SAS 只在出力时耗电（hold / 指向）。武装且已对准（死区约 0.5°）不耗。
5. Agent `pointState` / `driveBurn` 按同一 SAS 费率付钱，agent 不能白指向。
6. Rails / warp 必须走同一套 EC 步（按 warp dt 缩放，影子 + `1/r^2`）。不走的话夜里加速白嫖。这是硬刀。
7. 食：先挡当前 SOI 天体；在 Kerbin SOI 再挡 Mun（Mun 能遮你）。0.1.x 不做船自己挡板。
8. 合理零件，不造超级件：
   - `pod-mk1` 自带 50 EC；`pod-mk2` 150 EC
   - `batt-z100`：Z-100 Battery，Utility，径向，8 kg，100 EC，约 0.2 m
   - `panel-oxstat`：OX-STAT Photovoltaic，Utility，径向，6 kg，Kerbin（1 AU）0.8 EC/s，不展开
   OX-STAT 是静态侧翼（展向径向伸出，不是沿堆叠竖贴）。无展开键。
   以后可做 `batt-z400` 堆叠、一块展开板。不进第一批刀。
9. 不改火箭物理、不改星球大小、不把 EC 作弊灌满。

费率与太阳（未飞，不是遥测）：

- SAS 出力 **0.5 EC/s**（各舱相同）。E1 若「物理 hold 耗干」太快/太慢只许微调这一数。
- 通量 1.0 取 `BODIES.kerbin.orbitRadius`；`flux = (rKerbin / rKerbol)²`。太阳矢量用 `getInertialState` 指向 Kerbol，**不用** `flight.js` 里装饰用的 `SUNDIR`。
- 一艘一个 `st.ec`，容量 = 活零件 `ecCap` 之和。丢级按容量比例拆池，不造电。
- 新文件 `src/power.js`：`stepEC` / 通量 / 食。`stepAttitude` 只在 `ec>0` 时给 `podTorque`。不要重写轨道积分。

库存船（E3）：指挥舱段（host 0）挂 **两块 OX-STAT（`sym: 2`，90°/270°）+ 一块 Z-100（180°）**，丢级不断电，0.1.6 夜间/滑行任务还能飞。助推最后一节 XL（与 `legs-xl` 同宿主：Express 16 / Reuser 19 / Hauler 23）再挂一块 Z-100，回收翻转不空电。不在助推上加板。两块翼同一面：太阳在那一面时两块都发电（通量 1 约 1.6）。背面两块都是 0。

玩法：短脚本 + 结点 agent。检查要能看见 EC / 影子 / 距日出。新人类操作必须有 MCP；第一批没有展开键，所以不新造控制工具，只把电写进遥测。

版本保持 0.1.1.x（四位 0.<era>.<minor>.<build>，默认只加 build）。没飞过的数不写进病例。

## 边界

第一版不做：

- 展开板、跟踪阵、RTG、燃料电池、离子
- 无人核心锁死、探针电力门
- 船自己挡板
- 新按键 / 新人类操作（因而无新控制 MCP）
- 改火箭物理、改星球大小、Ike / Jool
- 把 EC 作弊灌满，或 rails 跳过电
- 发明没飞过的遥测
- 升 1.x
